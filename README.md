# App Venta de Celulares

Este proyecto está destinado al desarrollo de una aplicación para la venta de celulares. Fue creado en la asignatura **Ingeniería de Software II**.

## Descripción

La aplicación tiene como objetivo facilitar la compra y venta de dispositivos móviles, ofreciendo una interfaz intuitiva y funcionalidades que mejoren la experiencia del usuario.
